### ⚙️ What You Can Customize:
1. **General & WhatsApp**:
   - WhatsApp Number (Updates all direct buttons, inquiry forms, and floating widgets).
   - Phone, Email, Location, Brand Name, Subtitle.
   - Top Announcement Bar text & Offer Link query.
   - Floating chat bubble text.
2. **Hero Section**:
   - Main titles, badges, and subtitles.
   - **Typewriter animated keywords**: Add/remove/change keywords cycling on the hero section.
   - Button texts (CTA 1 & CTA 2).
   - 4 Trust Badges & icons.
3. **Services Manager (Full CRUD)**:
   - ➕ Add New Service
   - ✏️ Edit Service titles, icons, descriptions, bullet points, and WhatsApp query templates.
   - 🗑️ Delete any service.
4. **Portfolio Projects (Full CRUD)**:
   - ➕ Add New Demo Card
   - ✏️ Edit Project Title, Category (*Business, E-Commerce, Portfolio, Landing Page*), icons, tags, and descriptions.
   - 🗑️ Delete projects.
5. **Pricing Packages**:
   - Change prices, package names, delivery turnaround, feature checklists, and toggle the "🔥 Most Popular" badge.
6. **Why Choose Us & 4-Step Process**:
   - Customize workflow steps and value propositions.
7. **FAQ Manager (Full CRUD)**:
   - ➕ Add, edit, or delete FAQ questions and answers.
8. **Footer & Branding**:
   - Edit footer copyright and short bio summary.
9. **Backup & Export Center**:
   - **💾 Save Changes**: Instantly syncs and updates your live `index.html`.
   - **📥 Download Standalone `index.html`**: Exports a self-contained production file with all your customizations permanently embedded.
   - **📥 Backup / Export JSON**: Download your settings for safekeeping.
   - **🔄 Factory Reset**: Restore original default templates anytime.
